# UX_GUIDELINES.md

# Guías de Experiencia de Usuario

## Propósito

Definir los principios de experiencia de usuario que deberán seguir todos los módulos de Plataforma INTRA.

---

# Principios

- Priorizar flujos de trabajo sobre CRUD tradicionales.
- Reducir la navegación entre pantallas.
- Mostrar únicamente la información necesaria.
- Evitar información duplicada.
- Priorizar acciones rápidas.
- Mantener consistencia visual entre módulos.

---

# Organización

Siempre que sea posible utilizar:

- Dashboard
- Expedientes
- Tarjetas
- Indicadores
- Paneles
- Acciones rápidas

Evitar múltiples pantallas para un mismo proceso.

---

# Workflows

Los procesos deberán representarse como un flujo.

Ejemplo:

Configuración

↓

Aplicación

↓

Seguimiento

↓

Resultados

↓

Acciones

El usuario siempre deberá saber en qué etapa se encuentra.

---

# Indicadores

Los dashboards deberán mostrar:

- Estado actual
- Pendientes
- Avance
- Acciones necesarias

Evitar dashboards con únicamente botones.

---

# Navegación

- Reducir clics.
- Evitar pantallas repetidas.
- Priorizar modales cuando sea conveniente.
- Mantener breadcrumbs.

---

# Lineamientos de Desarrollo

Antes de crear una nueva pantalla verificar:

- ¿Ya existe una similar?
- ¿Puede integrarse al flujo existente?
- ¿Puede resolverse desde el expediente?
- ¿Realmente necesita una nueva vista?

---

# Regla de Oro

El sistema debe guiar al usuario.

El usuario nunca debe preguntarse cuál es el siguiente paso.
